# Record: Direct Pixel Painting System

- **Date**: 2026-09-06
- **Status**: WIP
- **Task Summary**: Implement direct 1:1 pixel painting on the canvas using the selected palette color, with real-time brush strokes, Bresenham interpolation, onion skinning, and frame persistence.

---

## 1. Goal / Context

The user specified:
> "sólo manejamos pixeles, y del tamaño que cuadre con el diseño
> por defecto, la acción del click será pintar el pixel con el colos seleccionado"

We are transitioning the editor to operate purely on discrete pixels matching the sprite's defined resolution. By default, clicking or dragging on the canvas artboard paints pixels with the currently active palette color, aligned 1:1 with the sprite pixel grid and transparency damero.
