## 1. Goal & Context

Add a standardized `Makefile` to simplify and automate key developer workflows:
- `make install`: Installs dependencies (`npm`, checks for `wasm-pack`).
- `make test`: Runs Rust test suite (`cargo test`).
- `make build`: Builds release Rust targets and WebAssembly packages (`wasm-pack build --target web`).
- `make up`: Serves the application locally on `http://localhost:3000`.
