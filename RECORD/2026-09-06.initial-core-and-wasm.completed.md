## 1. Goal & Context

Establish the initial architecture and foundational codebase for **Spritemotion** as outlined in the project roadmap:
- Concrete data model for 2D multi-layer sprite animation.
- Hierarchical parent-child matrix composition with local pivot points.
- Continuous keyframe interpolation (Linear, Step, Easing, Cubic Bezier).
- Discrete step frame-swapping for sub-sprites.
- WebAssembly bindings (`wasm-bindgen`) for integration with the upcoming `jq79` UI.

---

## 2. Changes Implemented

### Rust Engine Architecture
1. **`Cargo.toml`**:
   - Configured `rlib` and `cdylib` targets.
   - Integrated `serde`, `serde_json`, and optional `wasm-bindgen`.
2. **`src/math.rs`**:
   - `Vec2`: 2D point/vector operations with linear interpolation.
   - `Affine2D`: 3x3 affine transform matrix (`mul`, `inverse`, `transform_point`, `determinant`, `to_array`).
   - `from_trs_pivot`: Constructs local affine matrices applying translation, rotation, and scale relative to anchor pivot offsets.
3. **`src/model.rs`**:
   - Data types: `Project`, `ProjectMeta`, `SheetAtlas`, `SpriteFrame`, `Layer`, `LayerTracks`, `Keyframe<T>`, `Transform2D`, `Easing`.
   - Complete JSON serialization and deserialization support.
4. **`src/eval.rs`**:
   - `AnimationEngine`: Evaluates animation state at any arbitrary frame `t`.
   - `sample_scalar_track` & `sample_vec2_track`: Evaluates continuous curves with easing support.
   - `sample_discrete_track`: Implements strict step-based image swaps without blending.
   - Recursive parent-child hierarchy matrix resolution with cycle prevention and world opacity inheritance.
   - Z-index sorted output emitting a flat list of `RenderItem`.
5. **`src/wasm.rs`**:
   - Exported `SpritemotionWasm` interface exposing `load_project`, `evaluate_frame_json`, and metadata accessors.

### Examples & Documentation
- **`examples/sample_walk.json`**: 3-layer hierarchical character animation project (Torso -> Head, Torso -> Arm).
- **`tests/integration_test.rs`**: Integration test asserting multi-layer evaluation over 24 frames.

- **`.gitignore`**: Ignoring build artifacts and target directories.
