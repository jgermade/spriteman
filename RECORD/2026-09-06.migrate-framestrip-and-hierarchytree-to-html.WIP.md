# Work Record: Migration of FrameStrip and HierarchyTree to native jq79 HTML Components (WIP)

## 1. Goal / Context
Migrate the remaining two complex UI components, `HierarchyTree.ts` and `FrameStrip.ts`, to native jq79 Single-File Components:
- `src/components/HierarchyTree.html`
- `src/components/FrameStrip.html`
This completes the full frontend component architecture transition to jq79 Single-File Components with declarative templates and `<script :setup lang="ts">`, eliminating imperative DOM building and unneeded wrapper classes.

## 2. Planned Tasks
1. **HierarchyTree.html**:
   - Create native jq79 template matching `.hierarchy-panel` layout.
   - Declarative layer iteration with `:each="layer in validLayers"`.
   - In-place double-click rename via reactive conditional (`:if="renamingLayerId !== layer.id"` / `:else <input>`).
   - Declarative drag-and-drop event bindings for reordering and reparenting layers.
   - Layer action buttons (visibility toggle, relative-to-parent toggle, delete, select).
   - Bottom '+ Añadir Capa' button.
2. **FrameStrip.html**:
   - Create native jq79 template matching `.framestrip-container`.
   - Animation clips tabs strip with `:each="a in animations"`.
   - Complete transport and action toolbar: Play/Pause, Prev, Next, Undo, Redo, Duplicate, Delete, Onion Skin, Group Selection, Frame counter.
   - Declarative timeline frames reel with intermediate group wrappers, superimposed active group pill (with Pivot & Ungroup actions), frame cells, lock badges, and thumbnail previews.
   - Add new frame cell button (+) at end with drag-to-insert capabilities.
   - Touch drag support for mobile / PWA environments.
3. **EditorView Integration**:
   - Import `HierarchyTreeComponent` from `./components/HierarchyTree.html` and `FrameStripComponent` from `./components/FrameStrip.html`.
   - Mount both components with reactive state and callbacks.
   - Update state listeners to assign properties reactively to `this.hierarchyTree.data` and `this.frameStrip.data`.
   - Remove deprecated `HierarchyTree.ts` and `FrameStrip.ts`.
4. **Verification**:
   - Verify build with `npm run build` (`wasm-pack` and `vite build`).
   - Test in browser via `browser_subagent` on sample projects, checking playback, frame selection, layer reordering, thumbnail rendering, and renaming.
