# Work Record: App-like Layout, Project Picker Modal, WASMFS Storage, and Single-Frame New Project (WIP)

- **Date**: 2026-09-06
- **Status**: WIP
- **Author**: Antigravity Assistant & Jesús Germade

---

## 1. Goal & Context

Address user feedback to make Spritemotion feel like a professional desktop/PWA application:
1. **App-like Layout**: Full-viewport layout (`100vh`, zero page scrolling), docked center canvas workspace, pinned bottom timeline, and docked right tool sidebar.
2. **Startup Project Picker Modal**: Modal on open with options to create a new project or open an existing saved file.
3. **WASMFS Virtual Storage**: Virtual file system storage service (`storage.service.ts`) for persisting and retrieving projects.
4. **Single-Frame Initial State**: New projects start with exactly 1 initial frame (`total_frames: 1`) and a centered base layer.
5. **Strict Component Isolation**: `components/` strictly import ONLY `helpers/` or other `components/`.

---

## 2. Planned Changes

- **`src/services/storage.service.ts`**: Virtual WASMFS file system backed by persistent browser storage.
- **`src/components/ProjectModal.ts`**: Clean modal component for New Project and Open File selection.
- **`src/services/project.service.ts`**: Add `createNewProject(name, width, height, fps)` with single initial frame.
- **`src/views/EditorView.ts`**: Integrate top app bar actions, modal wiring, and layout dock.
- **`src/index.html`**: Pure application CSS shell (`100vh`, fixed viewport, docked toolbars).
