# Record: Draggable .frame-cell.new for Inserting Frames

- **Date**: 2026-09-06
- **Status**: WIP
- **Task Summary**: Add a `.frame-cell.new` element to the right of the last frame cell in the timeline strip, allowing clicking to append a new frame, and dragging to insert a frame at any position between existing frames.

---

## 1. Goal / Context

The user requested adding a `.frame-cell.new` button/cell to the right of the last frame in the animation timeline reel. This element should serve two purposes:
1. Click to append a new frame (copying previous frame data by default).
2. Drag and drop between previously added frames to insert a new frame at that specific chronological position.
