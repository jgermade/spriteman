# Layer Translation, Relative Positioning, Color Swap & Timeline Growth — Completed

## Goal / Context
Address five user requests for Spritemotion:
1. Palette swatch badges show `I` (Izquierdo / Color 1) and `D` (Derecho / Color 2) instead of numerical `1` / `2`.
2. Holding `SHIFT+CTRL` and dragging on the canvas moves/offsets the active layer (`onTranslateLayer`).
3. Nested/child layers have a toggle button (`🔗 Rel` / `🔓 Abs`) allowing relative position to parent or absolute position.
4. Holding `CMD` or `ALT` temporarily activates `btn-swap-colors`, swapping primary and secondary colors until released.
5. The timeline container (`.framestrip-container`) dynamically grows vertically so that its content (clip tabs, toolbar, active group pill, reel) is never cut off.

## Implemented Changes
1. **Palette Badges & Temporary Color Swap (`PixelPalette.ts`)**:
   - Swatch badges now render `I`, `D`, and `I|D` instead of `1`, `2`, `1|2`.
   - Dual color slot tags updated to display `I` and `D`.
   - Added key listeners on `window` for `Meta` and `Alt` (`keydown`, `keyup`, `blur`). When held, `isTempSwapped` flips primary and secondary colors and adds `.active` class to `.btn-swap-colors` with visual rotation and glow.
2. **Layer Translation Gesture (`CanvasStage.ts` & `ProjectService.ts`)**:
   - Added `onTranslateLayer?: (deltaX: number, deltaY: number) => void` callback to `CanvasStageOptions`.
   - Holding `SHIFT+CTRL` sets cursor to `move` and initiates layer translation drag.
   - `projectService.translateLayer(layerId, deltaX, deltaY, frameIndex)` translates `default_transform` and any keyframes on the current frame, triggering full re-evaluation.
3. **Relative Positioning for Child Layers (`HierarchyTree.ts`, `eval.rs`, `model.rs`)**:
   - In Rust core `engine/src/model.rs`: added `#[serde(default = "default_true")] pub relative_to_parent: bool` to `Layer`.
   - In `engine/src/eval.rs`: updated `resolve_world` so that when `relative_to_parent` is `false`, the layer evaluates with `Affine2D::IDENTITY` parent matrix (absolute coordinates).
   - Rebuilt WebAssembly package via `wasm-pack build engine --target web --out-dir ../src/wasm/pkg`.
   - In `HierarchyTree.ts`: added `🔗 Rel` / `🔓 Abs` toggle button (`.btn-relative-toggle`) for child layers with `onToggleLayerRelative` callback.
4. **Auto-Growing Timeline (`src/index.html`)**:
   - Updated `.timeline-docked-panel` CSS to `height: auto; min-height: 168px; max-height: 48vh; flex-shrink: 0; overflow-y: auto;`.
   - Updated `.framestrip-container` to `min-height: 100%; height: auto; gap: 0.65rem; padding: 0.65rem 0.85rem;`.
   - Content expands comfortably without clipping.
5. **EditorView Wiring (`src/views/EditorView.ts`)**:
   - Connected `onTranslateLayer` and `onToggleLayerRelative` to `CanvasStage` and `HierarchyTree`.
   - Updated subscriptions to supply complete multi-animation and group states to `frameStrip.update(...)`.
