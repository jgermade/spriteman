## 1. Goal & Context

Refactor project layout to support a modular PWA frontend architecture under `src/`:
- Move Rust core from `src/` to `engine/` to free `src/` for frontend code.
- Implement the requested frontend directory layout:
  - `src/wasm/`: WASM engine bridge and TypeScript typings.
  - `src/helpers/`: Pure utility functions (canvas, math, formatting).
  - `src/components/`: Isolated UI components (strictly importing ONLY other `components/` or `helpers/`).
  - `src/services/<name>.service.ts`: State management and WASM coordination.
  - `src/views/`: View containers connecting components and services.
  - `src/index.html`: Main PWA entrypoint.
- Enable full PWA capabilities (manifest, offline service worker, responsive standalone mode).
