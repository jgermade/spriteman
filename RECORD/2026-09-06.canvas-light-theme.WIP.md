# Record: Canvas Light Theme Implementation

**Date:** 2026-09-06  
**Status:** WIP  

---

## 1. Goal / Context

The user requested: *"usa un tema claro en el canvas"* (use a light theme in the canvas).
The canvas viewport, workbench backdrop, artboard, grid lines, and cursor need to be updated to a sleek, modern light theme that offers high clarity for pixel art editing.

---

## 2. Planned Changes

1. **`src/index.html`**:
   - Update `.canvas-viewport-panel` to use a modern light studio gradient backdrop (`#eef2f6` to `#dbe4ee`).
   - Style `.canvas-hud-overlay` badges, reset view button, and hint pills for crisp light-theme legibility with soft shadows and clear slate borders.
2. **`src/components/CanvasStage.ts`**:
   - Change artboard background from dark `#0a0f18` to pure white `#ffffff` with a subtle elevation drop shadow.
   - Update pixel grid lines from semi-transparent white to soft slate/gray (`rgba(0, 0, 0, 0.08)` and `rgba(0, 0, 0, 0.05)`).
   - Update artboard boundary stroke to crisp `#0284c7` (primary accent).
   - Update onion skinning color to high-contrast blue (`#0284c7`) with readable alpha.
3. **`src/helpers/canvas.helper.ts`**:
   - Update `drawPixelCursor` to render an inverted dual-border outline (`rgba(0,0,0,0.65)` and `#ffffff`) so the hover indicator is 100% visible on both light and dark pixels.
   - Update `drawPivotGizmo` crosshair colors for light theme contrast.
