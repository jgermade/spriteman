# RECORD: Pivot Visibility Strictly Bound to Active Interpolation Group

**Date**: 2026-09-07  
**Status**: Completed  
**Type**: UI/UX & Canvas Logic Refinement  

---

## 1. Goal / Context
The canvas pivot gizmo (crosshairs) was previously visible across all frames and layers because the editor logic fell back to `activeLayer.default_transform.pivot` or `activeLayer.pivot` when evaluating pivot coordinates. This caused unwanted visual clutter on regular drawing frames where no interpolation group was configured.

The user requirement states:
> *"el pivote sólo debería verse cuando se active en su grupo de interpolación correspondiente"*  
> (The pivot should only be visible when activated in its corresponding interpolation group).

---

## 2. Tasks & Changes

### A. Pivot Binding & Visibility Logic (`src/views/EditorView.html`)
- Refactored `syncPivotState`:
  - Retrieves the active interpolation group for the current frame via `projectService.getActiveLayerGroupForFrame(currentInt)`.
  - Checks if pivot editing mode is toggled on (`canvasService.isPivotMode()`).
  - If both `activeGroup` exists and `isPivotMode` is true:
    - Passes the group's pivot (`activeGroup.pivot` or defaults to canvas center) to `canvasService.setPivot(p)`.
  - If there is no active group or pivot mode is inactive:
    - Deactivates pivot mode if no group is present (`canvasService.setPivotMode(false)` and `frameStrip.data.isPivotMode = false`).
    - Calls `canvasService.setPivot(null)`, completely hiding the pivot gizmo from the canvas stage.
  - Eliminated legacy fallbacks to layer-level default transforms (`default_transform.pivot`).
- Hooked `syncPivotState()` into:
  - Animation frame updates & seeks (`animationService.onFrameChange`).
  - Frame selection & stepping (`onSelectFrame`, `onStep`).
  - Layer selection changes (`onSelectLayer`).
  - Group creation and deletion (`onGroupFrames`, `onUngroupFrames`).
  - Group pivot mode toggle (`onToggleGroupPivotMode`).
  - Animation switches (`onSelectAnimation`, `onAddAnimation`, `onDeleteAnimation`).

### B. Canvas Stage Integration (`src/services/canvas.service.ts` & `src/components/CanvasStage.html`)
- `canvasService.drawStage()` respects `this.pivot`: when `this.pivot === null`, the pivot crosshair, circular handle, and coordinate labels are not drawn.
- When `isPivotMode` is true and a valid `activeGroup` pivot is present, the canvas renders the interactive pivot crosshair and allows repositioning via drag gestures.
