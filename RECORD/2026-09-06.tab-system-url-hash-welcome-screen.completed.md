## 1. Goal & Context

Fulfill user requirements for project management, tab navigation, and startup flow:
1. **Welcome Screen when No Project is Open**: If no project is currently open, the editor is NOT rendered behind the dialog; instead, a clean startup screen is displayed with options to create a project or open an existing one.
2. **Direct Project Opening**: If one or more projects are open, the application skips the startup screen and opens the active project directly in the editor.
3. **Multi-Project Tabs**: Support multiple open projects switchable via tabs in the top application bar, with tab close buttons (✕) and an add tab button (+).
4. **URL Hash Routing**:
   Encode open tabs and the active tab in the URL hash following the specified pattern:
   `#tabs=<id1>,#<active_id>,<id3>`
   where the active/selected tab is prefixed with `#`.
   If all tabs are closed, the hash is cleared and the Welcome Screen is presented.
5. **Strict Component Isolation**: Confirmed that all components in `src/components/` import ONLY from `helpers/`.

## 2. Changes Implemented

### Tab & Hash Routing Service
- **`src/services/tabs.service.ts`**:
  - `parseTabsHash(hash)`: Extracts tab list and identifies the active tab (prefixed with `#`).
  - `formatTabsHash(tabs, activeTab)`: Produces `#tabs=<id1>,#<active_id>,<id3>`.
  - `openTab(id)`, `selectTab(id)`, `closeTab(id)`: Manages state and synchronizes with `window.location.hash` and the browser `hashchange` event.

### Components (Strictly Isolated)
- **`src/components/ProjectTabs.ts`**:
  - Topbar tab strip displaying open project names, active highlight, close buttons (✕), and `+` button.
- **`src/components/WelcomeScreen.ts`**:
  - Clean startup screen displayed when no project is open (`tabs.length === 0`).
  - Contains "Create New Project" (with 1 initial frame) and "Open Saved Project" (WASMFS storage list, demo sample, JSON upload).
  - Only imports from `../helpers/palette.helper`.

### Controller & View
- **`src/views/EditorView.ts`**:
  - Conditionally displays `WelcomeScreen` when `tabs.length === 0` (hiding the editor workspace completely).
  - When a project is open, mounts the full workspace directly and loads the active tab from WASMFS.
  - Wires tab selection, creation, and closing with URL hash updates.
- **`src/index.html`**:
  - Styles for project tabs strip, tab items, active states, and welcome screen hero cards.
