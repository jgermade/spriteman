# Record: Damero Pixel Resolution Alignment (1:1 Sprite Pixels)

- **Date**: 2026-09-06
- **Status**: completed
- **Task Summary**: Align the transparency checkerboard ("damero") and the pixel grid with the defined sprite pixel resolution (e.g. 16x16, 32x32, 64x64, 128x128).

---

## 1. Goal / Context

Previously, the canvas background checkerboard ("damero") used an arbitrary 8px screen tile size drawn over the viewport dimensions rather than matching the defined sprite artboard resolution. When creating or editing pixel art at resolutions like 16x16, 32x32, or 64x64, each checkerboard square should represent exactly one sprite pixel (1:1 scale in sprite space).

---

## 2. Tasks & Changes

1. **Pure Canvas Helpers ([canvas.helper.ts](file:///Users/joshua/dev/joshua/spritemotion/src/helpers/canvas.helper.ts))**:
   - Updated `drawPixelCheckerboard` to take `(ctx, startX, startY, spriteWidth, spriteHeight, c1, c2)`:
     - Iterates over each integer coordinate $(x, y)$ in $[0, \text{spriteWidth}-1] \times [0, \text{spriteHeight}-1]$.
     - Draws a $1 \times 1$ sprite pixel rectangle at $(startX + x, startY + y)$ alternating colors (`#111823` and `#192332`).
   - Updated `drawPixelGrid` to take `(ctx, startX, startY, spriteWidth, spriteHeight, lineWidth, lineColor)`:
     - Draws crisp vertical and horizontal grid lines across the exact $1 \times 1$ pixel cell boundaries.
     - With `lineWidth = 1 / zoom`, the grid lines remain exactly 1 screen pixel wide regardless of zoom level.

2. **Canvas Stage Component ([CanvasStage.ts](file:///Users/joshua/dev/joshua/spritemotion/src/components/CanvasStage.ts))**:
   - In `redraw()`:
     - Invoked `drawPixelCheckerboard(this.ctx, -halfSw, -halfSh, this.spriteWidth, this.spriteHeight)`.
     - Invoked `drawPixelGrid(this.ctx, -halfSw, -halfSh, this.spriteWidth, this.spriteHeight, 1 / this.zoom)` when `zoom >= 4`.
   - Guaranteed strict component isolation (components only import from `helpers/` or other `components/`).
