# RECORD: Persistent Layer Selection, Independent/Linked Content Movement, and Drag Performance Optimization

**Date**: 2026-09-07  
**Status**: Completed  
**Type**: Architecture & Performance Enhancement  

---

## 1. Goal / Context
Users reported three issues with layer management and canvas interaction:
1. **Persistent Layer Selection**: There must always be a layer selected, defaulting to the base layer (`layer_base` / `layers[0]`), avoiding `null` selection states.
2. **Independent vs. Linked Layer Content Movement**: The pixel content and transform of each layer must move independently, unless child layers are linked to their parent (`relative_to_parent !== false`, active by default). Moving a parent layer moves its linked children, while moving a child layer moves only that child without disturbing the parent or siblings.
3. **Elimination of Drag Lag (Input Lag)**: Dragging layer content previously felt sluggish with severe input lag due to full undo snapshots, JSON stringification, wasm reloads, and WASMFS file writes executing synchronously on every single pixel of mouse movement.

---

## 2. Tasks & Changes

### A. Persistent Layer Selection (`src/services/project.service.ts`)
- Modified `selectLayer(layerId)`: If `layerId` is `null` or invalid, automatically falls back to `layers[0].id` (base layer).
- Modified `setProjectJson(json)`: Validates `selectedLayerId` against parsed layers; if empty or invalid, automatically selects the base layer (`layers[0].id`).
- Modified `deleteLayer(layerId)`: Automatically re-assigns `selectedLayerId` to an adjacent remaining layer or `layers[0].id`.
- Initialized new projects (`createNewProject`) with `selectedLayerId: 'layer_base'`.

### B. Per-Layer Pixel Content & Linked Hierarchy Movement (`src/services/project.service.ts`)
- Added `frame_pixels?: Record<number, Record<string, string>>` to `LayerData`.
- Implemented `getCompositeFramePixels(frameIndex)`: Composes all visible layers sorted by `z_index` into a unified frame pixel map.
- Implemented `getLayerFramePixels(layerId, frameIndex)`: Retrieves isolated pixels for a specific layer.
- Updated `setPixels`, `setPixel`, `erasePixels`, `erasePixel`: Directs pixel operations to the currently selected layer (`selectedLayerId`), maintaining layer content isolation while keeping the composite view synchronized.
- Updated frame lifecycle (`duplicateFrame`, `insertFrame`, `deleteFrame`, `reorderFrame`): Propagates frame pixel changes across individual layer pixel maps.
- Enhanced `translateLayer(layerId, deltaX, deltaY, frameIndex, isFinal)`:
  - Identifies target layer and all linked descendants (`child.parent_id === parent.id && child.relative_to_parent !== false`).
  - Translates target layer transforms and shifts target layer pixels.
  - Recursively shifts pixels for linked descendant layers while leaving unlinked layers untouched.
  - When moving a child layer, only that child layer moves; the parent remains fixed.

### C. Drag Performance Optimization (Input Lag Removal) (`src/components/CanvasStage.html` & `src/views/EditorView.html`)
- Added `onStartTranslateLayer` callback to `CanvasStage.html` and wired it to `projectService.startLayerTranslation(selectedId)`.
- A single undo snapshot is created at the start of the drag gesture, preserving full undo/redo history without bloating the stack.
- During active dragging (`mousemove`), `onTranslateLayer(dx, dy, false)` executes with `isFinal = false`:
  - Directly updates layer transforms and pixels in memory and triggers canvas redraw.
  - Completely skips heavy JSON re-serialization, wasm reloads, and disk/WASMFS writes during the drag.
- On gesture end (`mouseup` / `mouseleave`), `onTranslateLayer(0, 0, true)` finalizes the movement, commits the JSON, and writes to storage once.
