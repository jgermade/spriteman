# Record: Pixel Art Animation Workflow, Reordering, Thumbnails, Motion Interpolation, Layer Creation, and Rotation Pivot Gizmo

**Date:** 2026-09-06  
**Status:** Completed  

---

## 1. Goal / Context

The goal was to align Spritemotion with its pure pixel-first vision:
1. Eliminate all dummy placeholder boxes and shapes from the canvas stage. The artboard must exclusively render discrete pixels, grid, onion skinning, and optional user-defined pivot gizmos.
2. Provide a user-configurable rotation axis (pivot) represented by a red circle with crosshairs for any layer.
3. Make all `.frame-cell` buttons in the timeline draggable so users can reorder frames intuitively.
4. Replace the frame cell button content with miniature, crisp previews (thumbnails) rendered dynamically from the frame's pixels.
5. Provide multi-frame consecutive range selection (selecting $\ge 3$ consecutive frames) with an action to interpolate motion across intermediate frames, replacing their pixel content.
6. Add an "Add Layer" placeholder (`.layer-item.new`) at the bottom of the layer hierarchy panel to create new layers on demand.

---

## 2. Tasks & Changes

### A. Pure Canvas & Pivot Gizmo (`src/helpers/canvas.helper.ts`, `src/components/CanvasStage.ts`)
- Removed all hardcoded dummy rectangles and bounding box drawing routines from `drawRenderItem` and `CanvasStage.redraw()`.
- Added `drawPivotGizmo`: renders a red circular pivot point with crosshairs at the layer's origin/pivot coordinates.
- Added `renderThumbnailToCanvas`: scales frame pixels crisply into thumbnail canvas elements using nearest-neighbor rasterization.
- Added `setPivot`, `setPivotMode`, and `onSetPivot` in `CanvasStage` allowing users to click directly on the canvas grid to position the rotation axis.

### B. Project Service Extensions (`src/services/project.service.ts`)
- Added `addLayer(name?, parentId?)`: adds a new layer and selects it.
- Added `setLayerPivot(layerId, pivotX, pivotY)`: updates the layer's pivot transform and coordinates.
- Added `reorderFrame(fromIndex, toIndex)`: shifts pixel maps and layer track keyframe indices to maintain timeline integrity when frames are dragged and reordered.
- Added `interpolateMotion(startFrame, endFrame, easing)`: calculates centroid translation offsets between `startFrame` and `endFrame` and computes interpolated pixel coordinates for all intermediate frames.

### C. Live Thumbnails & Frame Reordering (`src/components/FrameStrip.ts`, `src/index.html`)
- Replaced empty thumbnail placeholders with `<canvas class="cell-thumb-canvas" width="44" height="44">`.
- Added HTML5 drag-and-drop support to all `.frame-cell:not(.new)` to enable interactive frame reordering.
- Implemented range selection (`Shift+Click`) and dynamic `⚡ Interpolar` button when $\ge 3$ consecutive frames are selected.

### D. Layer Hierarchy & Add Layer Placeholder (`src/components/HierarchyTree.ts`)
- Added `.layer-item.new` button at the bottom of the layer list with callback `onAddLayer`.
- Added `📍 Pivote` toggle button on active layer items to activate canvas pivot placement mode.

### E. App Integration (`src/views/EditorView.ts`)
- Wired `onSetPivot`, `onReorderFrame`, `onInterpolateFrames`, and `onAddLayer` into `projectService` and `animationService`.
- Synchronized frame pixels into `frameStrip.update(...)` for immediate thumbnail re-rendering.
