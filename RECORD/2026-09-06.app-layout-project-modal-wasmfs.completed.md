## 1. Goal & Context

In response to user feedback, transform Spritemotion into a full-screen desktop/PWA pixel art animation workstation:
1. **Full-Viewport Desktop App Layout**: `100vh` non-scrolling window with fixed top menu bar, centered responsive canvas viewport, docked bottom timeline, and docked right tool sidebar.
2. **Project Picker Dialog**: Modal displayed upon startup allowing the user to create a new project or open existing projects from WASMFS storage or upload JSON.
3. **WASMFS Virtual Storage**: Persistent client-side virtual file system (`src/services/storage.service.ts`) storing and retrieving project files.
4. **Single-Frame Initial State**: Newly created projects start with exactly 1 initial frame (`total_frames: 1`) and a centered base layer.
5. **Strict Component Isolation**: Confirmed that all modules in `src/components/` import ONLY from `helpers/`.

---

## 2. Changes Implemented

### Storage Layer (WASMFS)
- **`src/services/storage.service.ts`**:
  - Virtual file system manager with `listFiles`, `saveFile`, `readFile`, and `deleteFile`.
  - Backed by persistent browser storage under `wasmfs:projects:`.

### Project Service
- **`src/services/project.service.ts`**:
  - Implemented `createNewProject(name, width, height, fps)` initializing `total_frames: 1` and a single centered root layer at `(width/2, height/2)` with keyframes on frame 0.

### Components (Strictly Isolated)
- **`src/components/ProjectModal.ts`**:
  - Modal with tabs for "New Project" (name, pixel size presets, FPS) and "Open Project" (listing WASMFS saved files, demo walk button, and file upload input).
  - Only imports from `../helpers/palette.helper`.

### Views & Layout
- **`src/views/EditorView.ts`**:
  - Full application bar with `📄 New`, `📁 Open`, `💾 Save (WASMFS)`.
  - Live project title, pixel size badge, and FPS badge.
  - Docked layout wiring center canvas, bottom timeline, and right tools column.
- **`src/index.html`**:
  - Full-screen `100vh` styles, flexbox/grid docks, zero window scrolling, and dark pixel art styling.
