- **Date**: 2026-09-06
- **Status**: WIP

## 1. Goal / Context

Upgrade SpriteMotion to a complete pixel-first animation workflow:
1. Remove remaining vector placeholder boxes on canvas.
2. Allow artists to set and reposition the rotation axis (red pivot circle) on any layer.
3. Allow dragging any `.frame-cell` to reorder frames.
4. Replace `.frame-cell` content with miniature pixel art thumbnail previews.
5. Provide multi-frame range selection in timeline to interpolate pixel motion across intermediate frames.
6. Add `.layer-item.new` in the hierarchy panel to quickly create layers.
