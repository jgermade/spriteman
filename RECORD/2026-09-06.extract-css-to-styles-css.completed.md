# Extract CSS from index.html to styles.css

## Goal / Context
Refactor `src/index.html` by extracting all internal stylesheets (`<style>...</style>`) into an external stylesheet `src/styles.css` and linking it via `<link rel="stylesheet" href="./styles.css" />`. This improves separation of concerns, keeps `index.html` lightweight and readable, and allows Vite to bundle and process the CSS bundle independently.

## Tasks & Changes
1. **Extracted Styles**:
   - Created `src/styles.css` containing all CSS rules (global reset, typography, theme variables, layout grid, toolbar, canvas workspace, sidebar panels, layer hierarchy, palette, inspector, timeline, modal dialogues, etc.).
2. **Linked External Stylesheet**:
   - Updated `src/index.html` to reference `<link rel="stylesheet" href="./styles.css" />`.
   - Removed ~1820 lines of inline styles from `src/index.html`.
