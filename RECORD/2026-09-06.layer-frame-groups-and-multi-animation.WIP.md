# Layer Frame Groups & Multi-Animation Reels — WIP

## Goal / Context
Implement layer-specific consecutive frame grouping with localized pivot points and motion interpolation, along with multi-animation project support (multiple `.frames-reel` clips per character/project, e.g. `idle`, `walk`, `jump`).

## Objectives
1. **Layer Frame Groups (`LayerFrameGroup`)**:
   - Model groups per layer: `id`, `layer_id`, `name`, `start_frame`, `end_frame`, and `pivot?: { x, y }`.
   - On selecting $\ge 2$ consecutive frames (`Shift + Click`), display `📦 Agrupar` instead of immediate interpolation.
   - For frames inside a group, display visual styling (`.frame-cell.in-group`) and provide group controls:
     - `📍 Ubicar Pivote`: place rotation axis for this specific layer & frame group on the canvas.
     - `⚡ Interpolar`: interpolate pixel motion across intermediate frames within the group.
     - `✕ Desagrupar`: dissolve the frame group.
2. **Multi-Animation Clips**:
   - Store multiple animations per project (e.g. `idle`, `walk`, `attack`), each maintaining its own total frames, FPS, frame pixels, and layer frame groups.
   - Provide animation clip tabs (`.animation-tabs-strip`) with `+ Nueva Animación` above the frame reel.
   - Switch active animation seamlessly, updating timeline, canvas, and playback.

## Planned Changes
- `src/services/project.service.ts`: Update project model with `animations` dictionary and active animation tracking; add `LayerFrameGroup` CRUD methods and group-based pivot/interpolation.
- `src/services/animation.service.ts`: Synchronize active animation playback with selected clip.
- `src/components/CanvasStage.ts`: Render localized pivot based on the active layer's group at the current frame; allow setting group pivot.
- `src/components/FrameStrip.ts`: Add animation clip tabs, `📦 Agrupar` button on consecutive frame selection, in-group cell indicators, and group toolbar (`📍 Ubicar Pivote`, `⚡ Interpolar`, `✕ Desagrupar`).
- `src/views/EditorView.ts`: Wire group creation, group pivot, group interpolation, and animation clip switching.
- `src/index.html`: Styles for animation tabs, group indicators, and group action controls.
