# RECORD: Fix Cursor and Painted Pixel Alignment

**Date**: 2026-09-07  
**Status**: Completed  
**Type**: Bug Fix & Canvas Viewport Math Refinement  

---

## 1. Goal / Context
Users reported an offset/misalignment between the mouse cursor position and the pixel cell highlighted or painted on the canvas:
> *"hay un problema con el cursor y el pixel a pintar, no son coincidentes"*  
> (There is a problem with the cursor and the pixel to paint, they are not coincident).

The root cause was traced to two compounding factors introduced during the canvas component modularization:
1. `CanvasStage.html`'s `ResizeObserver` attempted to scale the canvas pixel buffer by `window.devicePixelRatio` (`canvas.width = Math.round(width * dpr)`), which on macOS Retina displays doubled the internal canvas buffer (e.g. 2x).
2. However, the 2D rendering pipeline in `canvasService.redraw()` and pointer calculation in `canvasService.getSpritePixelAtPointer()` computed the viewport center `centerX` using `w / 2` and `containerRect.width / 2` without matching coordinates, causing an enormous (hundreds of pixels) offset between where the mouse clicked and where the artboard rendered.

---

## 2. Tasks & Changes

### A. Viewport Resolution Alignment (`src/components/CanvasStage.html`)
- Reverted canvas buffer sizing to 1:1 CSS pixel sizing (`canvas.width = Math.round(width)` and `canvas.height = Math.round(height)`), matching the original robust design from `CanvasStage.ts`.
- Removed `ctx.scale(dpr, dpr)` and inline CSS dimension overrides so that the canvas buffer matches the CSS bounding box 1:1.
- Updated all pointer event listeners (`mousedown`, `mousemove`, `touchstart`, `touchmove`, `wheel`, `handleResetView`) to consistently query `canvas.getBoundingClientRect()` directly.
- Passed explicit `canvas.width` and `canvas.height` to `canvasService.getSpritePixelAtPointer()` and `canvasService.zoomAtPoint()`.
- Added CMD/ALT temporary secondary color swap detection to `mousedown` for consistent drawing feedback.

### B. Coordinate Transformation Consistency (`src/services/canvas.service.ts`)
- Updated `getSpritePixelAtPointer(clientX, clientY, containerRect, canvasWidth?, canvasHeight?)` to use the exact same dimensions `w` and `h` as `redraw()`.
- Updated `zoomAtPoint(factor, clientX, clientY, containerRect, canvasWidth?, canvasHeight?)` to ensure anchor centering math remains strictly identical to stage centering.
