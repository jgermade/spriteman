# Record: Layer Hierarchy Drag-and-Drop Organization

**Date:** 2026-09-06  
**Status:** WIP  

---

## 1. Goal / Context

The user requested: *"que la jerarquía de capas se pueda organizar con drag and drop"* (that the layer hierarchy can be organized with drag and drop).
The objective is to allow users to drag layer items in the Layer Hierarchy panel to reorder their stacking position (Z-index) as well as nest or reparent layers under parent layers with clear visual drop targets.

---

## 2. Planned Changes

1. **`src/services/project.service.ts`**:
   - Add `reorderLayer(layerId: string, targetIndex: number, newParentId?: string | null)`:
     - Detects and prevents circular hierarchy dependencies.
     - Moves the layer to the desired index and updates `parent_id`.
     - Normalizes `z_index` values across all layers.
2. **`src/components/HierarchyTree.ts`**:
   - Make all layer items draggable with a drag handle (`⋮⋮`).
   - Implement HTML5 Drag and Drop events (`dragstart`, `dragover`, `dragleave`, `drop`, `dragend`).
   - Compute drop target zones:
     - Top edge: insert before.
     - Bottom edge: insert after.
     - Center: nest as child of target layer.
   - Display visual drop cues (`drop-before`, `drop-after`, `drop-child`).
3. **`src/views/EditorView.ts`**:
   - Wire `onReorderLayer` callback from `HierarchyTree` to `projectService.reorderLayer`.
   - Synchronize with `animationService` and save project.
4. **`src/index.html`**:
   - Add styling for drag handle, dragging state, insertion lines, and child nesting drop cues.
