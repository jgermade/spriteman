# Record: Draggable .frame-cell.new for Inserting Frames

- **Date**: 2026-09-06
- **Status**: completed
- **Task Summary**: Added `.frame-cell.new` to the right of the last frame cell in the timeline strip, enabling click-to-append and drag-to-insert between existing frames.

---

## 1. Goal / Context

Provide a seamless, tactile pixel-art animation workflow where artists can quickly append new frames or insert frames at any arbitrary position in the timeline by dragging an interactive `.frame-cell.new` element into place.

---

## 2. Tasks & Changes

1. **Project Service ([project.service.ts](file:///Users/joshua/dev/joshua/spritemotion/src/services/project.service.ts))**:
   - Implemented `insertFrame(targetIndex: number, copyPrevious = true): number`:
     - Shifts all keyframes with `frame >= targetIndex` by $+1$ across all property tracks (`position`, `rotation`, `scale`, `opacity`, `sprite_frame`).
     - Increments `meta.total_frames`.
     - Automatically copies the preceding frame's keyframe data into the newly inserted frame for animation continuity.
   - Refactored `addFrame(copyPrevious = true)` to delegate to `insertFrame(this.state.meta.total_frames, copyPrevious)`.

2. **FrameStrip Component ([FrameStrip.ts](file:///Users/joshua/dev/joshua/spritemotion/src/components/FrameStrip.ts))**:
   - Updated `FrameStripOptions.onAddFrame` signature to `(targetIndex?: number) => void`.
   - Appended a draggable `<button class="frame-cell new">` at the end of the reel with a `+` badge and dashed styling.
   - Click handler: appends a frame at the end of the timeline.
   - HTML5 Drag and Drop handlers:
     - Detects hover position on any `.frame-cell` (left half inserts before, right half inserts after).
     - Dynamically renders a pulsing neon-cyan `.frame-insert-slot` with a `+` badge showing the exact insertion slot.
     - On `drop`, invokes `onAddFrame(targetIndex)`.
   - Touch drag support:
     - Touch events (`touchstart`, `touchmove`, `touchend`, `touchcancel`) with floating touch ghost avatar (`.frame-drag-ghost`) and element detection via `document.elementFromPoint` for mobile/tablet/PWA use.

3. **Editor View ([EditorView.ts](file:///Users/joshua/dev/joshua/spritemotion/src/views/EditorView.ts))**:
   - Updated `onAddFrame: (targetIndex?: number) => { ... }`:
     - Calls `projectService.insertFrame(targetIndex, true)` when `targetIndex` is specified, or `projectService.addFrame(true)` on append.
     - Reloads the Wasm engine and seeks to the newly inserted frame index.

4. **Styles ([index.html](file:///Users/joshua/dev/joshua/spritemotion/src/index.html))**:
   - Added styles for `.frame-cell.new`, `.cell-new-thumb`, `.frame-insert-slot`, `@keyframes slot-pulse`, and `.frame-drag-ghost`.
