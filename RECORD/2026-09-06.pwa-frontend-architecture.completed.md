## 1. Goal & Context

Reorganize the project to establish a modular, decoupled PWA frontend architecture under `src/` while cleanly isolating the Rust engine in `engine/`:
- Structure:
  - `src/wasm/`: WASM loader and TypeScript type definitions.
  - `src/helpers/`: Pure utility modules (canvas, math, format).
  - `src/components/`: Reusable UI components conforming to the strict isolation rule (only importing `helpers/` or other `components/`).
  - `src/services/<name>.service.ts`: State management and WASM coordination.
  - `src/views/`: View containers assembling components and binding services.
  - `src/index.html`: Entrypoint with PWA manifest, service worker, and responsive viewport.

---

## 2. Changes Implemented

### 1. Engine Relocation
- Moved Rust code into `engine/src/` and tests into `engine/tests/`.
- Configured root `Cargo.toml` as a Cargo workspace with member `engine`.
- Configured `wasm-pack` to build from `engine` directly into `src/wasm/pkg/`.

### 2. Frontend Modules
- **`src/wasm/index.ts`**: Singleton loader for `SpritemotionWasm` and shared TypeScript interfaces.
- **`src/helpers/`**:
  - `canvas.helper.ts`: Pure canvas utilities (`drawBackgroundGrid`, `drawRenderItem`, `CanvasRenderItem`).
  - `math.helper.ts`: Clamping, interpolation, and angular conversions.
  - `format.helper.ts`: Frame count, timing, and matrix formatting.
- **`src/components/`**:
  - `PlayControls.ts`: Transport buttons, scrubber bar, and frame counter.
  - `CanvasStage.ts`: Viewport renderer with grid and selection highlight.
  - `HierarchyTree.ts`: Interactive layer list with parent-child indentation.
  - `InspectorPanel.ts`: Layer property and matrix inspector.
  - *Verification*: Grep analysis confirms zero imports to `services/` or `views/`.
- **`src/services/`**:
  - `animation.service.ts`: Playhead state, timeline seeking, stepping, and frame evaluation loop.
  - `project.service.ts`: Document data management, layer selection, and JSON parsing.
  - `pwa.service.ts`: Service Worker registration, offline status tracking, and install prompts.
- **`src/views/`**:
  - `EditorView.ts`: Connects services to isolated components via reactive subscriptions.
- **PWA Assets**:
  - `src/manifest.webmanifest`: Application metadata, icons, standalone display mode.
  - `src/sw.js`: Service worker implementing stale-while-revalidate caching for offline readiness.
  - `src/icon-192.svg` & `src/icon-512.svg`: Scalable vector application icons.
  - `src/index.html`: Application HTML entrypoint.

### 3. Tooling & Build Scripts
