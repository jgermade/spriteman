# Record: Dual Color Palette and CMD/ALT Right-Click Implementation

**Date:** 2026-09-06  
**Status:** Completed  

---

## 1. Goal / Context

The user requested:
1. *"mientras se pulsa CMD (o ALT) el click izquierdo se comporta como click derecho"* (while holding CMD or ALT, left click behaves as right click).
2. *"en la paleta de colores mejor dos colores seleccionados, uno para el click izquierdo y otro para el click derecho"* (in the color palette, have two selected colors: one for left click and another for right click).

---

## 2. Tasks & Changes

### A. Dual Color Palette Component (`src/components/PixelPalette.ts`)
- Added two active color state properties: `primaryColor` (Color 1 / Left Click) and `secondaryColor` (Color 2 / Right Click / CMD / ALT).
- Designed the dual color picker header:
  - **`Izq` slot button**: shows Color 1 preview and active focus.
  - **`Der` slot button**: shows Color 2 preview and active focus.
  - **`⇄` swap button** (also bound to keyboard shortcut `X`) to instantly swap primary and secondary colors.
- Interactive Swatches:
  - Left-click on any swatch assigns to active slot (or Color 1).
  - Right-click (or CMD/ALT + click) on any swatch immediately assigns to Color 2.
  - Swatches render numerical badges (`1`, `2`, or `1|2`) and distinct borders (`selected-primary` in sky blue, `selected-secondary` in dashed rose red).

### B. Canvas Stage Secondary Color & Modifier Mapping (`src/components/CanvasStage.ts`)
- Separated `isCtrlHeld` (Zoom Mode) from `isCmdHeld` (Meta) and `isAltHeld` (Alt).
- In `mousedown` and `mousemove`:
  - When left-clicking normally, draws with `primaryColor`.
  - When right-clicking, OR when left-clicking with CMD (Meta) or ALT (Option) held, automatically paints with `secondaryColor`.
- Real-time Cursor & HUD update:
  - While CMD or ALT is held, the hover pixel cursor reflects `secondaryColor`, previewing exactly what color will be painted before clicking.
  - HUD hint reflects active secondary color mode while modifiers are held.

### C. Application Integration (`src/views/EditorView.ts`)
- Configured `PixelPalette` and `CanvasStage` to initialize with `primaryColor: '#000000'` and `secondaryColor: '#ffffff'`.
- Connected `onSelectPrimary`, `onSelectSecondary`, and `onSelectColors` to synchronize canvas colors.
- Updated stroke painting listener to save the active stroke color directly into `projectService`.

### D. UI Styling (`src/index.html`)
- Added styling for `.palette-header-dual`, `.dual-color-slots`, `.color-slot-btn`, `.btn-swap-colors`, and swatch selection badges (`.swatch-badge`).
