# Record: Direct Pixel Painting System

- **Date**: 2026-09-06
- **Status**: completed
- **Task Summary**: Implemented discrete 1:1 pixel painting on the canvas using the selected palette color, with real-time brush strokes, Bresenham interpolation, onion skinning, and frame persistence.

---

## 1. Goal / Context

The user specified:
> "sólo manejamos pixeles, y del tamaño que cuadre con el diseño
> por defecto, la acción del click será pintar el pixel con el colos seleccionado"

Transformed the canvas stage and project model into a dedicated pixel art painting workflow where all painting operates strictly on discrete 1x1 sprite pixels matching the defined resolution (e.g. 16x16, 32x32, 64x64, 128x128). Clicking on the canvas paints the targeted pixel with the active palette color by default.

---

## 2. Tasks & Changes

1. **Pure Canvas Helpers ([canvas.helper.ts](file:///Users/joshua/dev/joshua/spritemotion/src/helpers/canvas.helper.ts))**:
   - Implemented `getLinePixels(x0, y0, x1, y1)` using Bresenham's algorithm to interpolate continuous strokes during fast mouse dragging without dropping pixels.
   - Implemented `drawPixels(ctx, startX, startY, pixels, alphaOverride, tintColor)` to draw discrete 1x1 sprite pixels with optional ghosting/tint for onion skinning.
   - Implemented `drawPixelCursor(ctx, startX, startY, px, py, color, zoom)` to render a crisp 1x1 target cell indicator highlighting the active color and target pixel before clicking.

2. **Pixel Palette Component ([PixelPalette.ts](file:///Users/joshua/dev/joshua/spritemotion/src/components/PixelPalette.ts))**:
   - Added `getActiveColor(): string` to expose the currently selected swatch color.
   - Verified strict component isolation (only imports from `helpers/`).

3. **Project Service ([project.service.ts](file:///Users/joshua/dev/joshua/spritemotion/src/services/project.service.ts))**:
   - Added `frame_pixels: Record<number, Record<string, string>>` into `ProjectState` and JSON serialization.
   - Added `getFramePixels`, `setPixel`, `setPixels`, `erasePixel`, and `erasePixels` methods.
   - Integrated pixel copying into `insertFrame`, `duplicateFrame`, and `deleteFrame` so that new frames inherit the previous frame's pixels.

4. **Canvas Stage Component ([CanvasStage.ts](file:///Users/joshua/dev/joshua/spritemotion/src/components/CanvasStage.ts))**:
   - Added `getSpritePixelAtPointer(clientX, clientY)` to compute exact integer pixel coordinates in sprite space:
     $px = \lfloor \text{stageX} + \text{halfSw} \rfloor$, $py = \lfloor \text{stageY} + \text{halfSh} \rfloor$.
   - Left click (button 0) and drag paints pixels with the active color.
   - Right click (button 2) erases pixels.
   - Middle click (button 1) or Shift/Alt+Drag pans the viewport.
   - Renders the 1x1 hover cursor highlight when hovering over the canvas artboard.
   - Draws onion skin pixels from previous frames in ghost cyan when onion skinning is enabled.

5. **Editor View ([EditorView.ts](file:///Users/joshua/dev/joshua/spritemotion/src/views/EditorView.ts))**:
   - Connected `onPaintStroke` from `CanvasStage` to `projectService.setPixels` / `erasePixels`.
   - Wired `PixelPalette.onSelectColor` to `CanvasStage.setActiveColor`.
   - Synchronized `canvasStage.setFramePixels` across frame stepping, timeline scrubbing, and animation playback.
