# Batch UI Improvements: Undo/Redo System, Layer Controls, Eraser Swatch, and Hotkeys — Completed

## Goal / Context
Deliver a comprehensive batch of user-requested workflow and UI enhancements to Spritemotion:
1. Selection outline and badge styling for `.frame-cell.in-range-selected`.
2. Onion-shaped SVG vector icon for `.btn-onion`.
3. Dedicated eraser swatch in `PixelPalette` that deletes pixels directly with primary or secondary clicks.
4. Hotkey `+` (and `=`) to quickly append frames to the active sequence.
5. Layer controls in `HierarchyTree`:
   - Visibility toggle (eye icon) on the left of layer items.
   - Free movement toggle (`btn-relative-toggle`) on the right for child layers (relative to parent by default, or free motion).
   - Layer deletion button (trash icon) on the right.
   - Inline layer renaming via double-click on layer names.
6. Full Undo / Redo system with `Cmd+Z`, `Cmd+Shift+Z`, and dedicated buttons in both the timeline toolbar and the top bar.

## Implemented Changes
1. **CSS Enhancements (`src/index.html`)**:
   - Added `outline: 1px solid #818cf8;` to `.frame-cell.in-range-selected`.
   - Added `background: #818cf8;` to `.frame-cell.in-range-selected .cell-num`.
   - Added `.btn-layer-action`, `.btn-layer-visibility`, `.btn-relative-toggle.rel-parent`, `.btn-relative-toggle.free-movement`, `.btn-layer-delete`, and `.layer-rename-input` styles.
   - Added `.palette-swatch.eraser` with checkerboard preview and eraser icon.
   - Added `.history-actions-group` for timeline toolbar undo/redo buttons.
2. **Onion SVG Icon (`src/components/FrameStrip.ts`)**:
   - Replaced stacked layer polygon SVG with an onion bulb SVG vector path.
3. **Eraser Swatch in Palette (`src/components/PixelPalette.ts`, `src/components/CanvasStage.ts`, `src/views/EditorView.ts`)**:
   - Added eraser swatch with sentinel value `'__eraser__'` and checkerboard styling.
   - Configured `CanvasStage` to delete pixels from local frame buffer during mouse paint strokes when eraser is active.
   - Routed eraser strokes in `EditorView` to `projectService.erasePixels()`.
4. **`+` Hotkey for Adding Frames (`src/views/EditorView.ts`)**:
   - Implemented global `keydown` shortcut handler in `EditorView`.
   - Pressing `+`, `=`, or `NumpadAdd` appends a new frame, reloads the engine, seeks to the new frame, and auto-saves the project.
   - Guards against active input/textarea/contentEditable focus.
5. **Layer Controls & Double-Click Rename (`src/components/HierarchyTree.ts`, `src/services/project.service.ts`, `src/views/EditorView.ts`)**:
   - Added `toggleLayerVisibility`, `renameLayer`, and `deleteLayer` to `ProjectService`.
   - Updated `HierarchyTree` to render:
     - Visibility toggle eye icon on the left (toggling visibility hides pixels and WASM rendering).
     - Drag handle and layer name.
     - Inline `<input>` on double-clicking layer name, committed on Enter or blur.
     - Free movement toggle icon button on the right for child layers.
     - Delete layer trash button on the right (disabled when only 1 layer exists).
     - Z-index badge.
6. **Undo / Redo Architecture (`src/services/project.service.ts`, `src/components/FrameStrip.ts`, `src/views/EditorView.ts`)**:
   - Added `undoStack` and `redoStack` in `ProjectService` holding JSON snapshots with a 50-step capacity.
   - Added automatic `pushUndoSnapshot()` before mutating methods: frame insertions/deletions/duplicates, layer edits, pixel strokes, animations, and dimensions.
   - Added `undo()`, `redo()`, `canUndo()`, and `canRedo()` methods in `ProjectService`.
   - Added undo and redo SVG icon buttons in `FrameStrip` toolbar and top bar.
   - Implemented `Cmd+Z`, `Cmd+Shift+Z`, and `Cmd+Y` shortcuts with automatic engine reloads and frame boundary clamping.
