# Work Record: Pixel Art UI, Frame-by-Frame Workflow, Speed Adjustments, and Palette (WIP)

- **Date**: 2026-09-06
- **Status**: WIP
- **Author**: Antigravity Assistant & Jesús Germade

---

## 1. Goal & Context

Refine the user experience for a professional pixel art animation workflow based on user feedback:
1. **Remove header nav-links**: Keep the header focused solely on the editor tool and PWA controls.
2. **Frame-by-Frame Timeline**: Provide an intuitive frame strip where frames are added one by one, by default duplicating the previous frame's poses for easy frame-to-frame tweaking.
3. **Animation Speed Settings**: Configurable FPS presets (6, 8, 12, 16, 24, 30 fps) and playback speed controls.
4. **Pixel Art Sizes & Color Palette**: Standard pixel canvas dimensions (16x16, 24x24, 32x32, 48x48, 64x64, 128x128), crisp pixel rendering, onion skinning, and curated pixel art color palette.
5. **Maintain strict component isolation**: Ensure `components/` ONLY import `helpers/` or other `components/`.

---

## 2. Planned Changes

- **`src/helpers/palette.helper.ts`**: Standard pixel art dimensions, presets, and curated 32-color palette.
- **`src/helpers/canvas.helper.ts`**: Checkerboard transparency pattern, pixel grid, onion skin rendering.
- **`src/components/FrameStrip.ts`**: Frame-by-frame reel with Add (+), Duplicate, Delete, and Onion Skin buttons.
- **`src/components/PixelPalette.ts`**: Pixel art color swatch picker for layers and sub-sprites.
- **`src/components/AnimationSettings.ts`**: Canvas size dropdown and FPS/speed controls.
- **`src/components/CanvasStage.ts`**: Zoomable pixel viewport (1x to 16x) with centered artboard.
- **`src/services/project.service.ts`**: Add `addFrame(copyPrevious)`, `deleteFrame`, `setCanvasSize`.
- **`src/services/animation.service.ts`**: Add speed multiplier, discrete frame navigation, onion skin frame retrieval.
- **`src/views/EditorView.ts`**: Re-wire components with the new pixel art layout.
- **`src/index.html`**: Clean header without nav-links.
