# Layer Frame Groups & Multi-Animation Reels — Completed

## Goal / Context
Implement layer-specific consecutive frame grouping with localized pivot points and motion interpolation, along with multi-animation project support (multiple `.frames-reel` clips per character/project, e.g. `idle`, `walk`, `jump`).

## Implemented Changes
1. **Multi-Animation Clips**:
   - Extended `ProjectState` with `animations: AnimationClipData[]` and `activeAnimationId: string`.
   - Added animation synchronization methods in `ProjectService`: `addAnimation`, `selectAnimation`, `renameAnimation`, `deleteAnimation`, `syncActiveAnimation`.
   - Added animation clip tabs strip (`.animation-tabs-strip`) above the frame reel with active highlight, frame count badge, and `+ Nueva Animación` button.
2. **Layer Frame Groups (`LayerFrameGroup`)**:
   - Added `groups?: LayerFrameGroup[]` per `LayerData` with `id`, `layer_id`, `name`, `start_frame`, `end_frame`, and optional localized `pivot: { x, y }`.
   - Range selection ($\ge 2$ consecutive frames) now shows `📦 Agrupar (X..Y)` button instead of direct interpolation.
   - Cells belonging to a group display in-group styling (`.frame-cell.in-group`) and pivot indicators (`.cell-pivot-dot`).
   - Group toolbar pill displays `📍 Ubicar Pivote` (sets localized pivot for this group), `⚡ Interpolar` (interpolates position across group frames), and `✕ Desagrupar`.
3. **Canvas & Engine Synchronization**:
   - `CanvasStage` resolves and renders the active group's pivot at the current frame.
   - Setting a pivot when an active group exists updates the group's pivot rather than the global layer pivot.
4. **Isolated Component Architecture**:
   - `FrameStrip.ts` defines its own local `AnimationClipItem` and `FrameGroupItem` interfaces, maintaining strict decoupling from service modules.
