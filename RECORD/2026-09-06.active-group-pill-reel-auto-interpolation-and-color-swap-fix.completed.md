# Group Pill in Reel, Auto-Interpolation & Color Swap Painting Fixes — Completed

## Goal / Context
Address specific feedback points:
1. When CMD/ALT is held down (activating `.btn-swap-colors`), left clicking on the canvas was not painting with the color displayed in slot 'I'.
2. Layer displacement gesture (`SHIFT+CTRL` / `SHIFT+CMD`) needed robust screen-space drag tracking and synchronous pixel shifting.
3. `.active-group-pill` should sit directly on top of the intermediate frames in the reel, because these intermediate frames are automatically generated and no longer directly editable.
4. The manual interpolate button is eliminated; interpolation is now completely automatic upon group creation and whenever an endpoint is modified.
5. Buttons inside `.active-group-pill` must only show icons (e.g. `📍` and `✕`).

## Implemented Changes
1. **Direct Palette Color Painting Fix (`CanvasStage.ts`)**:
   - In `CanvasStage.ts` (painting Mode D): left click (button 0) now always paints strictly with `this.primaryColor`, and right click (button 2) paints with `this.secondaryColor`.
   - Because `PixelPalette` already handles swapping `primaryColor` and `secondaryColor` dynamically on CMD/ALT/X, left-clicking directly paints with Color 'I' as displayed in the UI, eliminating the accidental double-swap.
2. **Layer Translation Dragging & Pixel Shifting (`CanvasStage.ts` & `ProjectService.ts`)**:
   - In `CanvasStage.ts`: switched `layerMoveStart` from bounded sprite coordinates to viewport screen client coordinates `(clientX, clientY)`.
   - Added support for both `SHIFT+CTRL` and `SHIFT+CMD` (`e.shiftKey && (e.ctrlKey || e.metaKey)`).
   - In `ProjectService.ts -> translateLayer`: shifts `layer.default_transform`, `layer.pivot`, `layer.tracks.position`, and translates existing pixels in `state.frame_pixels[frameIndex]` by `(deltaX, deltaY)`, triggering immediate visual feedback on the canvas.
   - Fixed WebAssembly URL resolution in `src/wasm/index.ts` using `import wasmUrl from './pkg/spritemotion_bg.wasm?url'` so `initWasm(wasmUrl)` resolves properly in both Vite dev and production bundles.
3. **In-Reel Group Pill & Locked Intermediate Frames (`FrameStrip.ts`, `EditorView.ts`, `index.html`)**:
   - In `FrameStrip.ts`: intermediate frames between `start_frame` and `end_frame` are wrapped in a `.group-intermediate-wrapper`.
   - Placed `.active-group-pill.in-reel` directly on top of the intermediate frames spanning across them, displaying `⚡ Grupo` with compact icon-only buttons:
     - `📍` for pivot toggle (`.btn-group-pivot`)
     - `✕` for ungroup (`.btn-group-ungroup`)
   - Removed the manual interpolate button (`⚡ Interpolar`).
   - Intermediate frame cells render with `.group-intermediate` styling and a locked badge (`🔒`), with direct canvas painting blocked in `EditorView.ts -> onPaintStroke`.
4. **Automatic Group Interpolation & Recalculation (`ProjectService.ts`)**:
   - `createFrameGroup` automatically interpolates pixel motion across the group immediately upon creation.
   - Added `autoRecalculateGroupsForFrame(frameIndex)`: whenever `setPixel`, `setPixels`, `erasePixel`, `erasePixels`, or `translateLayer` is invoked on an endpoint frame of a group, all intermediate frames are automatically recalculated in real time.
