# Work Record: Pixel Art UI, Frame-by-Frame Workflow, Speed Adjustments, and Palette

- **Date**: 2026-09-06
- **Status**: Completed
- **Author**: Antigravity Assistant & Jesús Germade

---

## 1. Goal & Context

In response to user feedback, transform the user interface into a dedicated pixel art animation environment:
1. **Remove Header Navigation Links**: The web app header now contains only branding and application indicators.
2. **Frame-by-Frame Workflow**: Frames are added one by one, duplicating the previous frame's poses by default for smooth frame-to-frame tweaking.
3. **Animation Speed Settings**: Adjustable playback speed and configurable FPS presets (6, 8, 12, 16, 24, 30 fps).
4. **Pixel Art Sizes & Color Palette**: Standard retro dimensions (16x16, 24x24, 32x32, 48x48, 64x64, 128x128), zoom levels (2x, 4x, 6x, 8x, 12x), pixel grid, onion skinning, and a curated 32-color palette.
5. **Strict Component Isolation**: Confirmed that all modules in `src/components/` import ONLY from `helpers/`.

---

## 2. Changes Implemented

### Helpers
- **`src/helpers/palette.helper.ts`**:
  - `STANDARD_PIXEL_SIZES`: 16x16, 24x24, 32x32, 48x48, 64x64, 128x128.
  - `PIXEL_ART_PALETTE`: 32 retro colors (DB32 / Endesga inspired).
- **`src/helpers/canvas.helper.ts`**:
  - `drawPixelCheckerboard`: Pixel art transparency grid.
  - `drawPixelGrid`: Pixel-level grid for precision editing.
  - `drawRenderItem`: Color tinting, selection outlines, and pivot points.

### Components (Strictly Isolated)
- **`src/components/FrameStrip.ts`**:
  - Frame-by-frame reel with direct frame selection cells.
  - `+ Add Frame` button (copies previous frame's poses by default).
  - `Duplicate` and `Delete` frame actions.
  - `🧅 Onion Skin` toggle button.
  - Play/Pause and Step transport buttons.
- **`src/components/PixelPalette.ts`**:
  - 32-color clickable swatches with active color indicator.
- **`src/components/AnimationSettings.ts`**:
  - Dropdowns for Canvas Size, Animation Speed (FPS), and Pixel Zoom.
- **`src/components/CanvasStage.ts`**:
  - Viewport scaled for pixel art with centered artboard, onion skinning, and checkerboard.

### Services & Views
- **`src/services/project.service.ts`**:
  - Added `addFrame(copyPrevious = true)`, `duplicateFrame(idx)`, `deleteFrame(idx)`, `setCanvasSize(w, h)`, and `setLayerColor(id, color)`.
- **`src/services/animation.service.ts`**:
  - Added `setFps`, `setSpeedMultiplier`, and onion skin frame evaluation.
- **`src/views/EditorView.ts`**:
  - Assembles all components and wires them to services.
- **`src/index.html`**:
  - Removed header `nav-links`.
  - Added pixel art responsive layout styles with crisp pixel rendering (`image-rendering: pixelated`).
