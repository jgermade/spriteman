# Record: Layer Hierarchy Drag-and-Drop Organization

**Date:** 2026-09-06  
**Status:** Completed  

---

## 1. Goal / Context

The user requested: *"que la jerarquía de capas se pueda organizar con drag and drop"* (that the layer hierarchy can be organized with drag and drop).
The objective was to allow users to intuitively reorder layer stacking (Z-index) as well as parent/child nesting by dragging and dropping layer items within the Layer Hierarchy panel.

---

## 2. Tasks & Changes

### A. Project Service Layer Reordering (`src/services/project.service.ts`)
- Added `reorderLayer(layerId: string, targetIndex: number, newParentId: string | null)`:
  - Traverses the hierarchy to guard against cyclic parent-child dependencies.
  - Slices and splices the layer into its new target position.
  - Updates `parent_id` when reparented.
  - Normalizes `z_index` across all layers to match their new array positions.
  - Updates raw JSON, persists changes, and notifies subscribers.

### B. Interactive Hierarchy Drag and Drop (`src/components/HierarchyTree.ts`)
- Marked each `.layer-item:not(.new)` as `draggable="true"`.
- Added a dedicated drag handle `⋮⋮` (`.layer-drag-handle`) with cursor styling.
- Implemented HTML5 Drag and Drop events:
  - `dragstart`: Stores `layer.id` and sets `effectAllowed = 'move'`.
  - `dragover`: Computes pointer ratio relative to item height to determine drop target:
    - `< 0.28`: Insert above (`.drop-before`).
    - `> 0.72`: Insert below (`.drop-after`).
    - `0.28..0.72`: Nest as child layer (`.drop-child`).
  - `dragleave` & `dragend`: Resets visual drag cues.
  - `drop`: Calculates target index and `newParentId`, invoking `onReorderLayer`.

### C. Application Controller Integration (`src/views/EditorView.ts`)
- Wired `onReorderLayer` from `HierarchyTree` into `projectService.reorderLayer`.
- Synchronized layer changes with `animationService.reloadProject` and auto-saved the project.

### D. CSS Styling (`src/index.html`)
- Added styles for `.layer-drag-handle` with hover highlights.
- Added `.layer-item.is-dragging` opacity and scale effects.
- Added `.drop-before` top indicator line, `.drop-after` bottom indicator line, and `.drop-child` dashed border nesting highlight.
