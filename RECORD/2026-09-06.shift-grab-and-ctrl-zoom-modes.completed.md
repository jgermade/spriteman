# Record: SHIFT Grab Mode & CTRL Zoom Mode

- **Date**: 2026-09-06
- **Status**: completed
- **Task Summary**: Implemented dedicated modifier modes: holding SHIFT activates grab/pan mode, holding CTRL activates zoom mode with scrubby/click zoom, and default click paints pixels.

---

## 1. Goal / Context

The user specified:
> "mientras se mantiene SHIFT: modo aguarre
> mientras se mantiene CTRL: modo zoom"

To provide a rapid, frictionless pixel art creation workflow, keyboard modifier keys now dynamically toggle the active viewport manipulation tool:
- **SHIFT**: Activates Grab / Pan mode (`cursor: grab` / `grabbing`). Dragging pans the canvas viewport without painting pixels.
- **CTRL** (and Meta/Cmd on macOS): Activates Zoom mode (`cursor: zoom-in` / `zoom-out`). Clicking or dragging zooms in/out anchored directly at the cursor point.
- **Default (no modifier)**: Paints discrete 1:1 pixels with the active palette color (`cursor: crosshair`).

## 2. Tasks & Changes

1. **CanvasStage Component ([CanvasStage.ts](file:///Users/joshua/dev/joshua/spritemotion/src/components/CanvasStage.ts))**:
   - Added modifier state tracking (`isShiftHeld`, `isCtrlHeld`, `isAltHeld`, `isMouseDown`).
   - Window event listeners for `keydown`, `keyup`, and `blur` to maintain modifier keys in real-time.
   - Dynamic cursor updates:
     - Default: `crosshair`.
     - SHIFT held: `grab` (and `grabbing` while dragging).
     - CTRL held: `zoom-in` (or `zoom-out` if Alt is also pressed).
   - Implemented `zoomAtPoint(factor, clientX, clientY)` anchoring the canvas zoom transform exactly under the pointer.
   - Scrubby zoom on vertical drag when holding CTRL, and click-to-zoom on single click.
   - Pan on drag when holding SHIFT (or middle mouse button).
   - Hid the 1x1 pixel hover highlight box while in SHIFT or CTRL mode so only the relevant cursor is shown.
