# Record: Migration to jq79 Components and $reactive Services

## Goal / Context
Upgrade and refactor the Spritemotion frontend architecture to take full advantage of **jq79 v0.7.1**:
1. Leverage reactive proxy state (`$reactive`) across core services (`project.service.ts`, `animation.service.ts`, `tabs.service.ts`, `pwa.service.ts`), deprecating manual `Set<Listener>` observer boilerplate while maintaining backward-compatible subscriptions.
2. Migrate UI components and views from imperative TypeScript DOM-building classes (`document.createElement`) to native jq79 single-file components (`.html`) with declarative templates and `<script :setup lang="ts">`.
3. Maintain 100% feature parity with pixel art canvas editing, frame manipulation, hierarchical layer trees, WASMFS project management, and URL hash routing.
