# Record: SHIFT Grab Mode & CTRL Zoom Mode

- **Date**: 2026-09-06
- **Status**: WIP
- **Task Summary**: Implement dedicated modal interaction keys: holding SHIFT enables grab/pan mode with hand cursor, and holding CTRL enables zoom mode with zoom cursor and scrubby/click zoom.

---

## 1. Goal / Context

The user requested:
> "mientras se mantiene SHIFT: modo aguarre
> mientras se mantiene CTRL: modo zoom"

Artists need quick keyboard modifier shortcuts to pan and zoom fluidly without switching active tools or interrupting their pixel painting workflow:
1. **Holding SHIFT**: Activates grab mode (`cursor: grab`/`grabbing`), clicking and dragging pans the canvas viewport without painting pixels.
2. **Holding CTRL** (and Meta/Cmd): Activates zoom mode (`cursor: zoom-in`/`zoom-out`), clicking zooms toward the cursor point, and dragging scrubs zoom smoothly.
