# 2026-09-07.modifier-behaviors-shift-layer-ctrl-loose-pixel.completed.md

## 1. Goal / Context
Redefine modifier key behaviors for canvas interaction to provide an intuitive, high-precision workflow:
- **SHIFT**: Drags the content of the active layer (and its linked children).
- **CTRL**: Drags individual loose pixels.
- **CMD**: Unchanged (keyboard shortcuts, undo/redo, temporary palette color swap, and wheel zoom).
- **SPACE / Middle-Click**: Seamless canvas panning.

## 2. Tasks & Changes
1. **Layer Content Drag via SHIFT (`CanvasStage.html` & `EditorView.html`)**:
   - Holding `Shift` now directly engages layer content movement (`isMovingLayer = true`) on mouse down, without requiring `Ctrl` or `Cmd`.
   - Cursor updates to `move` (or `grabbing` while moving).
   - In `mousemove`, translates layer pixels and updates both stage canvas and timeline thumbnail in real time.

2. **Loose Pixel Drag via CTRL (`CanvasStage.html`, `project.service.ts`, `canvas.service.ts`)**:
   - Implemented `startPixelMove`, `movePixel`, and `cancelPixelMove` in `project.service.ts`:
     - Creates a non-destructive drag baseline so dragged pixels do not corrupt or erase underlying cells they pass over.
     - Smoothly translates the selected loose pixel in memory and recomputes the composite frame at 60 FPS.
     - On mouseup, finalizes the pixel relocation, pushes a single undo snapshot to the undo history, and reloads WASM/JSON.
   - In `CanvasStage.html`:
     - When `isCtrlHeld` is active, hovering over an existing pixel displays `cursor: grab` and highlights the target pixel with a blue grab frame in `canvas.service.ts`.
     - Mouse down on a pixel starts `isDraggingLoosePixel`, setting `cursor: grabbing` and moving that individual pixel to the destination cell upon drag.
   - Removed old legacy click-zoom gesture from `Ctrl` in favor of the new loose pixel drag.

3. **Canvas Panning Ergonomics (`CanvasStage.html`)**:
   - Added `Space` key grab/pan mode (`cursor: grab` / `grabbing`) alongside middle-click (`e.button === 1`) and mouse wheel panning, ensuring users without a middle mouse button can effortlessly pan the viewport.

4. **CMD Preserved**:
   - Kept `Cmd+Z` / `Cmd+Y` / `Cmd+Shift+Z` undo/redo, temporary palette color swap on `Cmd` / `Alt`, and wheel zoom untouched.
