## 1. Goal & Context

Fulfill user requirements for project tab management and conditional view display:
1. **Welcome Screen when No Project is Open**: If no project is open, do NOT show the editor behind. Display a clean, focused startup screen with options to create or open projects.
2. **Direct Project Opening**: If one or more projects are open, open the active project directly without showing the modal.
3. **Multi-Project Tabs**: Support multiple open projects selectable via tabs in the top application bar, with close (✕) buttons and a `+` button.
4. **URL Hash Format**:
   Encode open tabs and the active tab in the URL hash following the specified pattern:
   `#tabs=<id1>,#<active_id>,<id3>`
   where the currently selected/active tab is prefixed with `#`.
   If all tabs are closed, hash is cleared and the Welcome Screen is shown.
5. **Strict Component Isolation**: Ensure all components in `src/components/` only import from `helpers/` or other `components/`.

---

## 2. Planned Changes

- **`src/services/tabs.service.ts`**: URL hash parser, tab state management (`openTab`, `selectTab`, `closeTab`), and `hashchange` synchronization.
- **`src/components/ProjectTabs.ts`**: Isolated tabs bar component with active tab highlight, close buttons, and add tab action.
- **`src/components/WelcomeScreen.ts`**: Isolated startup/welcome screen displaying new project form and WASMFS project list.
- **`src/views/EditorView.ts`**: Toggle between Welcome Screen and full editor based on active tab; synchronize tab switching with project loading.
- **`src/index.html`**: Tab bar and welcome screen CSS styles.
