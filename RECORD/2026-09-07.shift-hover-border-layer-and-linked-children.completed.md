# 2026-09-07.shift-hover-border-layer-and-linked-children.completed.md

## 1. Goal / Context
When hovering over the canvas with `CTRL` held, the editor highlights the border of the loose pixel that will be moved.
The user requested an analogous visual feedback for `SHIFT`: when hovering over the canvas with `SHIFT` held, highlight the border/silhouette of all the pixels of the layer that will be moved (and of linked child layers if relative movement is active).

## 2. Tasks & Changes
1. **Target and Linked Descendant Aggregation (`src/services/project.service.ts`)**:
   - Implemented `getActiveLayerMovingPixels(frameIndex)` in `projectService`.
   - Recursively traverses the layer hierarchy starting from the active layer to collect all child layers that have `relative_to_parent !== false`.
   - Gathers all pixel coordinates belonging to these layers on the specified frame.

2. **Perimeter Silhouette and Tint Rendering (`src/services/canvas.service.ts`)**:
   - Added `activeLayerPixels` state and `setActiveLayerPixels()` method to `CanvasService`.
   - In `canvasService.redraw()`, when `modifiers.isShiftHeld` and `this.hoverPixel` are active:
     - Fills the moving pixels with a subtle cyan tint (`rgba(56, 189, 248, 0.18)`).
     - Computes the outer boundary edges of the pixel cluster (where adjacent neighboring cells are empty/outside the cluster) and draws a crisp, high-contrast `#38bdf8` perimeter border.

3. **Hover Event Tracking with Shift (`src/components/CanvasStage.html`)**:
   - Updated pointer tracking on `mousemove` so that `canvasService.setHoverPixel(pixel)` is continuously updated even when `isShiftHeld` is true (instead of clearing it to null).
   - Ensured that pressing or releasing `Shift` immediately triggers `triggerRedraw()` to activate or dismiss the highlight outline in real time without requiring extra cursor movement.

4. **Synchronous Frame Pixel Propagation (`src/views/EditorView.html`)**:
   - Updated `canvasService.setFramePixels()` invocations across playback, scrubbing, layer translation, and pixel movement to pass `projectService.getActiveLayerMovingPixels(currentInt)`.
