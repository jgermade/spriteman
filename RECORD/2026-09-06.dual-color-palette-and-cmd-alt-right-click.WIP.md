# Record: Dual Color Palette and CMD/ALT Right-Click Behavior

**Date:** 2026-09-06  
**Status:** WIP  

---

## 1. Goal / Context

User requested:
1. *"mientras se pulsa CMD (o ALT) el click izquierdo se comporta como click derecho"* (while CMD or ALT is pressed, left click behaves as right click).
2. *"en la paleta de colores mejor dos colores seleccionados, uno para el click izquierdo y otro para el click derecho"* (in the color palette, have two selected colors: one for left click and another for right click).

---

## 2. Planned Changes

1. **`src/components/PixelPalette.ts`**:
   - Support two active colors: `primaryColor` (Left Click) and `secondaryColor` (Right Click / CMD / ALT).
   - Display dual color indicators in the palette header with active slot indicator and swap button (`⇄`).
   - Left-click on any swatch sets `primaryColor`; right-click (or CMD/ALT+click) sets `secondaryColor`.
   - Provide visual markers on the palette swatches for both selected colors.
2. **`src/components/CanvasStage.ts`**:
   - Separate `isCtrlHeld` (Zoom mode) from `isCmdHeld` (Meta) and `isAltHeld` (Alt).
   - When CMD or ALT is held, left click paints with `secondaryColor` instead of `primaryColor`.
   - Update hover pixel cursor to reflect `secondaryColor` when CMD or ALT is pressed.
   - Update HUD hints to inform the user about Left Click (Color 1), CMD/ALT or Right Click (Color 2), SHIFT (Grab), and CTRL (Zoom).
3. **`src/views/EditorView.ts`**:
   - Update `PixelPalette` and `CanvasStage` configuration to sync both `primaryColor` and `secondaryColor`.
   - Update stroke handler to write the respective color to `projectService`.
4. **`src/index.html`**:
   - Add styles for dual active color boxes, swap button, and palette swatch selection badges.
