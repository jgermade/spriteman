How the numbers were taken

  • Headless Chromium driving the real dev build, counters on clearRect / fillRect / toDataURL / localStorage.setItem / JSON.stringify.
  • Document under test: 24 frames × 3 layers × 64×64, ~22% fill (~2 226 composite pixels per frame, 2.0 MB JSON).
  • Absolute milliseconds are pessimistic (CPU-only rasterization); the operation counts are hardware independent.

Open decisions

  • Does the exported document keep frame_pixels, or reference a rasterized atlas instead? This drives Phase 2.
  • One shipped UI language — Spanish or English — per AGENTS.md §1.
  • Memory strategy once several project tabs can be open simultaneously.

Not started (backlog)

  • Spritesheet / atlas import (TexturePacker-compatible).
  • Rasterized spritesheet export (raster.rs).
  • Rotation and scale gizmos; easing-curve editing in the timeline.
