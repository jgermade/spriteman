What a cel looks like

  • { "p": ["#3a5f8a"], "r": [128, 0, 4, 1, 3964, 0] } — palette, then run-length pairs in row-major order.
  • Index 0 is transparent; the runs always cover the whole canvas, so a decoder needs nothing but meta.
  • An empty cel is left out of the document entirely.

Two bugs it fixed

  • A second animation clip inherited the first clip's artwork, because layer pixels were shared across clips.
  • Interpolated in-between frames lived only in the composite and disappeared on reload.

Reading old projects

  • v1 opens unchanged and is rewritten as v2 on the next save.
  • The active clip recovers artwork per layer; other clips only ever had a flattened image, which lands on the bottom layer.
